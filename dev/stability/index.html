Numerical Stability and Backward-Error Bounds

This page states the backward-error and spectral-accuracy bounds satisfied by the linear and spectral kernels in GeometricSolvers, together with their literature sources and the verification domain covered by the test suite (test/linear/stability.jl).

Throughout this page:

  • $T \in \{\texttt{Float32}, \texttt{Float64}, \texttt{ComplexF32}, \texttt{ComplexF64}\}$ denotes the problem element type and $R = \texttt{real}(T)$ its real precision, with machine epsilon $\varepsilon_R = \texttt{eps}(R)$.
  • $n$ denotes the matrix dimension and $\kappa_2(A) = \sigma_1(A) / \sigma_r(A)$ the 2-norm condition number of a matrix $A \in T^{n \times n}$ of numerical rank $r$.
  • The cited theorems bound each error by a low-degree polynomial in $n$ times $\varepsilon_R$, with the growth factor or the condition number where stated. The test suite asserts each bound with the explicit constant

    \[c = 16,\]

    a test threshold with a margin above the measured errors, not a constant derived from the theorems.

LU with Partial Pivoting (StaticLU, DenseLU, DeviceLU)

LUFactorization dispatches to:

  • StaticLU on SMatrix{n, n, T} (register-resident Gaussian elimination with partial pivoting),
  • DenseLU on host Array{T, 2} (LAPACK getrf! / getrs!), and
  • DeviceLU on GPU AbstractGPUArray{T, 2} backends such as JLArray and MtlArray (KernelAbstractions panel pivoting and trailing-submatrix update).

By Higham (2002, §9.3–9.4), Gaussian elimination with partial pivoting produces a computed solution $\hat{x}$ to $A x = b$ that is the exact solution of $(A + \Delta A)\hat{x} = b$, where $\|\Delta A\|_2 / \|A\|_2$ is bounded by $O(n \, \rho_n \, \varepsilon_R)$ for growth factor $\rho_n$. On systems with moderate pivot growth, the test suite verifies the normwise backward error bound

\[\frac{\|A \hat{x} - b\|_2}{\|A\|_2 \|\hat{x}\|_2 + \|b\|_2} \le c \cdot n \cdot \varepsilon_R, \qquad c = 16.\]

Householder QR (StaticQR, DenseQR, DeviceQR)

QRFactorization dispatches to:

  • StaticQR on SMatrix{n, n, T} (register-resident Householder reflections with standard complex sign selection),
  • DenseQR on host Array{T, 2} (LAPACK geqrf! / ormqr! / unmqr! and BLAS.trsv!), and
  • DeviceQR on GPU AbstractGPUArray{T, 2} backends (KernelAbstractions column-norm reduction and reflector application).

By Higham (2002, Theorem 19.4, §19.3), Householder QR factorization and triangular back-substitution are unconditionally backward stable, with a normwise backward error of order $n \, \varepsilon_R$. For a nonsingular square system $A x = b$, the test suite verifies the normwise backward error bound for the computed solution $\hat{x}$

\[\frac{\|A \hat{x} - b\|_2}{\|A\|_2 \|\hat{x}\|_2 + \|b\|_2} \le c \cdot n \cdot \varepsilon_R, \qquad c = 16.\]

SVD and Hermitian Jacobi Eigensolver (StaticSVD, DenseSVD, DeviceSVD, jacobi_eigen)

SVDFactorization dispatches to:

  • StaticSVD on SMatrix{n, n, T} (one-sided Jacobi orthogonalization of $A$ followed by column normalization and descending sort),
  • DenseSVD on host Array{T, 2} (LAPACK gesvd), and
  • DeviceSVD on GPU AbstractGPUArray{T, 2} backends (KernelAbstractions one-sided Jacobi sweeps with complex phase annihilation).

For Hermitian matrices H::SMatrix{n, n, T}, jacobi_eigen computes the spectral decomposition $H = V \operatorname{Diagonal}(\lambda) V^*$ by two-sided cyclic Jacobi sweeps.

By Demmel and Veselić (1992) and Higham (2002), these algorithms are backward stable, with errors of order $n \, \varepsilon_R$. The test suite verifies:

  1. Full-rank linear solve (ldiv!!): For $A$ of numerical rank $n$ ($\sigma_n / \sigma_1 > \sqrt{n} \, \varepsilon_R$), the pseudoinverse backsolve $\hat{x} = \hat{V} \hat{\Sigma}^{-1} \hat{U}^* b$ satisfies the normwise backward error bound

    \[\frac{\|A \hat{x} - b\|_2}{\|A\|_2 \|\hat{x}\|_2 + \|b\|_2} \le c \cdot n \cdot \varepsilon_R, \qquad c = 16.\]

  2. Singular values (singular_values on StaticSVD, fac.S on DenseSVD and DeviceSVD): The computed singular values $\hat{\sigma}_1 \ge \dots \ge \hat{\sigma}_n$ satisfy the Weyl relative bound

    \[\frac{\max_{1 \le i \le n} |\hat{\sigma}_i - \sigma_i|}{\sigma_1} \le c \cdot n \cdot \varepsilon_R, \qquad c = 16.\]

  3. Hermitian eigendecomposition (jacobi_eigen): On a Hermitian positive-definite matrix $H$ with exact eigenvalues $\lambda_1 \ge \dots \ge \lambda_n > 0$, the computed eigenpairs $(\hat{\lambda}, \hat{V})$ satisfy

    \[\frac{\|H \hat{V} - \hat{V} \operatorname{Diagonal}(\hat{\lambda})\|_2}{\|H\|_2} \le c \cdot n \cdot \varepsilon_R, \qquad \|\hat{V}^* \hat{V} - I\|_2 \le c \cdot n \cdot \varepsilon_R, \qquad \frac{\max_{1 \le i \le n} |\hat{\lambda}_i - \lambda_i|}{\lambda_1} \le c \cdot n \cdot \varepsilon_R,\]

    with $c = 16$.

Rank-Deficient SVD Minimum-Norm ldiv!!

When $A \in T^{n \times n}$ has exact rank $r < n$ with singular values $\sigma_1 \ge \dots \ge \sigma_r > 0 = \sigma_{r+1} = \dots = \sigma_n$ and $\sigma_r / \sigma_1 \gg \sqrt{n} \, \varepsilon_R$, SVDFactorization with factor precision $T$ (SVDFactorization()) across StaticSVD, DenseSVD, and DeviceSVD detects the numerical rank fac.rank == r by truncating singular values satisfying $\hat{\sigma}_i \le \sqrt{n} \, \varepsilon_R \, \hat{\sigma}_1$.

With a reduced factor precision $F$, the cutoff is $\sqrt{n} \, \varepsilon_{\operatorname{real}(F)} \, \hat{\sigma}_1$ instead, and a singular value at or below it counts as zero even where $\sigma_r / \sigma_1 \gg \sqrt{n} \, \varepsilon_R$ holds. For example, with $T = \texttt{Float64}$, SVDFactorization(Float32) gives fac.rank == 2 for $A = \operatorname{Diagonal}(1, 1, 10^{-9}, 0)$, whose rank is 3. The rank detection above and the bound below hold for the factor precision $T$ only.

By Demmel and Veselić (1992) and Higham (2002, §20.4), the truncated pseudoinverse solve ldiv!! approximates the exact minimum-norm least-squares solution $x_{\min} = V_{1:r} \Sigma_{1:r}^{-1} U_{1:r}^* b$ with relative forward error bounded by

\[\frac{\|\hat{x} - x_{\min}\|_2}{\|x_{\min}\|_2} \le c \cdot n \cdot \varepsilon_R \cdot \bigl(\kappa_2(A) + \kappa_2(A)^2 \tan\theta\bigr), \qquad \tan\theta = \frac{\|b - A x_{\min}\|_2}{\|A x_{\min}\|_2}, \qquad c = 16,\]

where $\kappa_2(A) = \sigma_1 / \sigma_r$ is the 2-norm condition number of the nonzero singular spectrum and $\theta$ is the angle between $b$ and the range of $A$. The term $\kappa_2(A)^2 \tan\theta$ is the residual term of least-squares perturbation theory; for a consistent system, $\tan\theta = 0$. The test suite draws $b$ with a component outside the range of $A$ and asserts the stronger bound $c \cdot n \cdot \kappa_2(A) \cdot \varepsilon_R \cdot \|b\|_2 / \|A x_{\min}\|_2$, which implies the one above because $\|b\|_2 / \|A x_{\min}\|_2 = \sqrt{1 + \tan^2\theta} \le 1 + \kappa_2(A) \tan\theta$.

Mixed-Precision Factorization and Scaled Solve (TF ≠ T)

When a factorization method is constructed with reduced factor precision TF (for example LUFactorization(Float32), QRFactorization(Float32), or SVDFactorization(Float32) applied to a problem with $T \in \{\texttt{Float64}, \texttt{ComplexF64}\}$ and factor storage type $F = \texttt{Float32}$ or $\texttt{ComplexF32}$), factorize!! scales $A$ by a power of two $2^{-e}$, converts the scaled matrix into precision $F$, and computes the factorization in $F$.

During ldiv!!, GeometricSolvers implements the scaled mixed-precision solve of Kelley (2023, eqs. 2.17–2.18):

  1. Compute the right-hand side scale $s = \max_i |b_i| = \|b\|_\infty$ in working precision $T$ (returning $0$ immediately if $s = 0$).
  2. Scale and downcast $\tilde{b} = F.(b / s)$ into factor precision $F$, preventing exponent underflow or overflow in reduced precision.
  3. Solve the factored system for $\tilde{x}$ in precision $F$.
  4. Rescale by $s \cdot 2^{-e}$ and convert back to working precision $T$.

For $T \in \{\texttt{Float64}, \texttt{ComplexF64}\}$, $\texttt{TF} = \texttt{Float32}$, $n \in \{4, 16, 64\}$ and $\kappa_2(A) \in \{10, 10^4\}$, the cases that the test suite covers, the resulting solution $\hat{x} \in T^n$ satisfies the normwise backward error bound at the coarser of the working precision $\varepsilon_R$ and the factor precision $\varepsilon_{\operatorname{real}(F)} = \texttt{eps}(\operatorname{real}(F))$:

\[\frac{\|A \hat{x} - b\|_2}{\|A\|_2 \|\hat{x}\|_2 + \|b\|_2} \le c \cdot n \cdot \max(\varepsilon_R, \varepsilon_{\operatorname{real}(F)}), \qquad c = 16.\]

For a reduced factor precision, as in these cases, the maximum is $\varepsilon_{\operatorname{real}(F)}$. For a wider factor precision, the rounding of $\hat{x}$ to $T$ limits the attainable backward error to the order of $\varepsilon_R$; the test suite does not cover this case.

The bound does not cover a truncated SVD solve. The SVD factor counts every singular value $\hat{\sigma}_i \le \sqrt{n} \, \varepsilon_{\operatorname{real}(F)} \, \hat{\sigma}_1$ as zero, and ldiv!! leaves out its direction. For example, with $T = \texttt{Float64}$, $F = \texttt{Float32}$, $A = \operatorname{Diagonal}(1, 1, 1, 10^{-9})$ and $b = e_4$, the factor has fac.rank == 3, the solve gives $\hat{x} = 0$, and the backward error is $1$. In the tested cases, $\kappa_2(A) \le 10^4 < 1 / (\sqrt{n} \, \varepsilon_{\texttt{Float32}})$, so every SVD factor there has numerical rank $n$.

Verification Matrix (test/linear/stability.jl)

Every bound above is verified in test/linear/stability.jl using random matrices with Haar-distributed orthogonal or unitary factors (test/helpers/randsvd.jl) and geometrically distributed singular values or eigenvalues:

  • Element types: $T \in \{\texttt{Float32}, \texttt{Float64}, \texttt{ComplexF32}, \texttt{ComplexF64}\}$ (ELTYPES).
  • Condition numbers: $\kappa_2 \in \{10, 10^4\}$ for 32-bit real precision ($R = \texttt{Float32}$) and $\kappa_2 \in \{10, 10^4, 10^8\}$ for 64-bit real precision ($R = \texttt{Float64}$); $\kappa_2 = 100$ with rank $r = n - 2$ for rank-deficient SVD; $\kappa_2 \in \{10, 10^4\}$ with $T \in \{\texttt{Float64}, \texttt{ComplexF64}\}$ and $\texttt{TF} = \texttt{Float32}$ for mixed-precision solves.
  • System dimensions: $n \in \{4, 16, 64\}$ for the full-rank and mixed-precision solves across dense (Array) and device (JLArray under allowscalar(false)) backends, $n \in \{4, 16\}$ for the rank-deficient SVD solve across dense and device backends, and $n \in \{4, 16\}$ across static (SMatrix{n, n, T}) kernels, which include jacobi_eigen.
