GeometricSolvers

Documentation for GeometricSolvers.

GeometricSolvers.GeometricSolvers — Module

Solvers with the problem/method/solver interface of SimpleSolvers, built so that the same solvers run on the CPU and on CUDA, ROCm and Metal devices through KernelAbstractions.

source

GeometricSolvers provides line searches, linear solvers and nonlinear solvers that run on the CPU and on CUDA, ROCm and Metal devices through KernelAbstractions. One solver loop serves three regimes, which the storage of the initial iterate selects:

  • R1: a Number or an SVector, with value semantics, on the host or in one GPU thread,
  • R2: a batch of small systems, one work-item per system on the CPU or a GPU, through solve_batch!,
  • R3: an in-place AbstractVector, on the CPU or on a device array.
julia> using GeometricSolvers

julia> x, status = solve(NonlinearProblem((x, p) -> x^2 - p), 1.0, Newton(), 2.0);

julia> x ≈ sqrt(2) && status.code === SUCCESS
true

Contents of this documentation

Manual

  • Getting started: problems, call forms, solve, init and solve!, options, status and return codes, parameters, and the SciML extension.
  • The three regimes: R1, R2 and R3, and how to choose one.
  • Methods by regime: the methods that run in R1, R2, R3 and the matrix-free R5, and the conditions of each.
  • Problem types: least squares, stationarity, reparametrization, deflation and elimination.

Algorithms

  • Nonlinear methods: Newton, GaussNewton, Picard, factor reuse and implicit differentiation.
  • Globalization: line searches, the dogleg trust region and Levenberg–Marquardt.
  • Linear solvers: static, dense, device and sparse factorisations, and the matrix-free GMRES.
  • Automatic differentiation: ForwardDiff, DifferentiationInterface and sparse Jacobians.
  • Composition and preconditioning: combinators, Anderson and Broyden acceleration, restricted additive Schwarz and RASPEN.

Architecture

  • CPU and GPU backends: the storage and reduction seams, dispatch, kernel-safe types, vendor libraries and device precision.
  • Mixed precision: the factorisation precision, the scaled solve and iterative refinement.
  • Numerical Stability and Backward-Error Bounds: the bounds of each factorisation that the test suite verifies.
